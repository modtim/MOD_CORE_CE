## What you may do without asking (nominative use)

You may use the MOD Marks in **nominative, factual, non-branding** ways,
including:

- Truthfully stating that your product, service, or fork **is based on**,
  **is compatible with**, **integrates with**, or **was forked from** "MOD
  Core" — e.g., "MyThing is built on MOD Core" or "a fork of MOD Core."
- Linking to the MOD Core project or its documentation.
- Referring to MOD Core by name in blog posts, talks, academic papers,
  comparison tables, tutorials, and similar factual/editorial content.
- Using the unmodified MOD Core logo in a "built with" / "powered by" credit
  list alongside other projects, at a reasonable size, without implying
  endorsement.
- Internal use (e.g., an internal fork named "MOD Core (internal)" for your
  own company's private deployment).

Nominative use must be truthful, must not imply Mod Tech Labs Inc.'s endorsement,
sponsorship, or certification of your product unless that has actually been
granted, and must not be styled to look like Mod Tech Labs Inc.'s own branding
(colors, logo lockups, domain names, etc.).

## What requires permission (brand use)

The following are **prohibited without prior written permission** from Mod Tech Labs Inc.

- Using "MOD", "MOD Core", or a confusingly similar name as, or as part of,
  **the name of your own product, project, company, or domain** — e.g., you
  may not name a fork "MOD Core Pro," "GetMOD," or similar,
  and you may not register a domain like `mod-core-hosting.com` implying
  affiliation.
- Using the MOD logo (or a confusingly similar mark) as **your own product's
  logo or primary branding**, including on a modified/re-skinned fork.
- Any use that suggests your offering **is** the official MOD Core project,
  **is** Mod Tech Labs Inc., or **is endorsed/certified by** Mod Tech Labs Inc., when it
  is not.
- Using the MOD Marks in a way that disparages Mod Tech Labs Inc. or MOD Core, or
  in connection with content that violates the project's
  [Code of Conduct](./CODE_OF_CONDUCT.md).
- Using the MOD Marks as part of the name of a **competing commercial hosted
  offering** built on this code without a separate agreement — e.g., "MOD
  Cloud Alternative" or similar naming intended to trade on the MOD name for a
  competing paid service.

## Forking MOD Core

You are welcome — the Apache-2.0 license explicitly allows it — to fork,
modify, and redistribute MOD Core's source code, including for commercial
purposes. **The license covers the code; it does not cover the name or
logo.** If you fork the project:

- **Do** pick your own name and logo for your fork/distribution that is not
  confusingly similar to "MOD" or "MOD Core."
- **Do** feel free to say, factually, "forked from MOD Core" or "based on MOD
  Core" (see Nominative use, above).
- **Don't** call your fork "MOD Core" (unqualified), "MOD Core X," or
  anything a reasonable user would mistake for the official project or for a
  Mod Tech Labs Inc. product.
- **Don't** reuse the MOD logo as your fork's own logo.

This mirrors common practice for Apache-2.0 / open-core projects with a
protected mark: the code is yours to use freely; the name is how users find
the project's official releases and get support from its maintainers.

may use the MOD Marks in their normal project capacity (e.g., referring to
"the MOD Core maintainers," presenting about MOD Core at conferences,
maintaining the project's official website/docs/social accounts on behalf of
the project). This is not a personal trademark license and does not survive a
maintainer's departure from the project for use outside that role.
