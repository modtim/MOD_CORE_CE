Elevation Requests

Just-in-time production-admin elevations (host shell, DB admin, Vault admin, Docker socket). Filing one opens a pending row that only a DIFFERENT platform admin may approve — the maker-checker is enforced by the server, and a refused self-approval is reported exactly as the server words it. Every row carries its state, who filed it, who decided it, the window it runs (start → end) and the time left in that window. A pending row that waits past the approval window is auto-revoked.
