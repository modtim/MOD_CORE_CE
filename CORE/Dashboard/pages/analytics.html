Stack rebalancer

                    
Automatically relocate running stacks to freer workers.
                        Off by default — this has never run against a live deployment, so turn it on deliberately
                        and watch the first few moves.

                    
                    
Only move a stack to a freer worker when it's at least this much better
                        (fractional, e.g. 0.10 = 10%). Higher = less churn.
