How Worker Management Works

  • Click Add Worker to generate a setup command for a new remote machine
  • Run the command on the target machine — it installs Docker, GPU drivers, and the worker agent
  • Workers with manual tokens appear as "Pending" until approved
  • Active workers can receive and process tasks
  • Click "Remove" on a worker to take it off this list
  • Workers are listed above
  • Workers offline for more than 5 minutes are marked as "Offline"
