Another user in this tenant

Tenant admins can end every session of another user in their own tenant (their account stays intact — this only kills their logins). The API exposes no way to list another user's sessions, so only the revoke action is offered.

Session rows are ephemeral auth records, not audit records — the revocations themselves are audited (SESSION_SIGN_OUT_SINGLE / SESSION_SIGN_OUT_ALL). Your own current session can also be ended from the "Sign out everywhere" button above; the per-user button below refuses to target you (403) because the self-service call exists.
