Installation Instructions

🪟 Windows Installation

  1. Download the MOD-Setup MSI installer (shown above when it has been published for this release)
  2. Double-click the .msi file, or run msiexec /i MOD-Setup-<version>.msi
  3. The installer registers the MOD worker as an SCM service (MODWorker) and installs the MODTray app in your user session
  4. Launch the tray app from the Start Menu; it tracks the local worker's health state
  5. No local worker on this machine? The tray app reports that honestly — use the enrollment one-liner on the Workers page to install the worker service first

🍎 macOS Installation

  1. Download the .dmg file
  2. Double-click to open the disk image
  3. Drag "MOD Platform Tray" to your Applications folder
  4. Open Applications and find "MOD Platform Tray"
  5. Right-click → Open (first time only to bypass Gatekeeper)
  6. The tray icon will appear in your menu bar (top-right)

🐧 Linux Installation

Option 1: AppImage (Universal)

  1. Download the .AppImage file
  2. Open terminal: chmod +x MOD-Platform-Tray-*.AppImage
  3. Run it: ./MOD-Platform-Tray-*.AppImage

Option 2: Debian/Ubuntu (.deb)

  1. Download the .deb package
  2. Install: sudo dpkg -i mod-platform-tray_*.deb
  3. Launch from applications menu
