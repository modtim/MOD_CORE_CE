# Verifying MOD Release Signatures

Community Edition release images and the worker binary are **not signed** at v1.0.0, and no release signatures or provenance attestations are published. Pull images by digest from a registry you trust, or build them from source with the dev-build override (see the install guide). To list the components in an image, see the [SBOM guide](https://github.com/modtim/MOD_CORE_CE/blob/main/docs/sbom.md).
