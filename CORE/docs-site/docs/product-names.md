# Product names

MOD groups its features into products. Each one has a short, memorable
name in the sidebar and a plain-language line saying what it does. The
table below is the whole set — nothing here changes a page address, a
route, an environment variable or a worker image name.

## Page tab names

The tabs inside a page use the page's name, a hyphen and the tab's
function. The Gearworks, Signpost, Citizens and Records names were chosen
by the owner. The Guard (Permissions) and the System page tab names (The City - ...) are proposed names, not yet confirmed. The Workers, Stacks and Cloud tabs on the System page keep the names of their own pages (Quadlings - Workers, Emeralds - Stacks, Balloon Cloud - Burst Accounts).

| Page | Tab names |
|---|---|
| Gearworks - Settings | Gearworks - Integrations, Gearworks - Secrets, Gearworks - Permission Settings, Gearworks - API Keys, Gearworks - AI Configuration, Gearworks - Knowledge Base, Gearworks - Stack TLS |
| Signpost - Help | Signpost - Cards, Signpost - Mind Map, Signpost - AI in this Platform |
| Signpost - Help doc cards | Signpost - Getting Started Guide, Signpost - Node Library, Signpost - API Reference, Signpost - Worker Setup, Signpost - Troubleshooting, Signpost - Full Documentation Site, Signpost - Open docs |
| Citizens - Users | Citizens - Users, Citizens - Invitations |
| The Guard - Permissions | The Guard - Data, The Guard - Secrets, The Guard - API Keys, The Guard - Templates |
| Records - Logs | Records - Workflow Runs, Records - System Tasks |
| The City - System | The City - System Health, The City - External, The City - Settings, The City - Usage Analytics, The City - Activity, The City - Platform Settings, The City - Change-Gate Report |

The mind map on the Help page shows the sidebar name for a box that matches a sidebar page (for example Signpost - Help, Toto - Workflows); every other box keeps its plain documentation title. The FAQ card about paid editions is not part of the Community Edition and keeps its plain title.
