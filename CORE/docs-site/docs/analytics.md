# Analytics & System

The area named **The City - System** shows how your tenant is using MOD and how the platform is doing.

## Usage analytics

See where your workflow runs and capacity go:

- **Cost (credits) per workflow / node** — informational only; CE does not meter or enforce credits.
- **Workflow runs** — counts, success/failure, durations.

Use this to spot expensive nodes, find failing workflows, and see how much capacity your deployment is using.

## System Status

A health view of the platform's services. If something looks slow or a run is stuck, check here first — it surfaces maintenance windows and service degradation.
